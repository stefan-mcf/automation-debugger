# Screenshot Evidence

All screenshots in this directory are local, synthetic, and public-safe. They are generated by `PYTHONPATH=src python scripts/capture_screenshots.py` after the CLI/API/report paths are real.

The generator renders readable dark proof panels, not browser or desktop captures. This keeps the evidence reproducible and avoids exposing live accounts, credentials, tabs, notifications, or private desktop context.

| File | What it proves |
|---|---|
| `01-flow-overview.png` | Failed fixture -> diagnosis -> correction/refusal -> replay/report evidence flow. |
| `02-cli-proof.png` | CLI can inspect a malformed date fixture and emit safety fields. |
| `03-openapi-endpoints.png` | Local API exposes `/health`, `/diagnose`, `/replay`, and `/report`. |
| `04-diagnosis-output.png` | Diagnosis JSON includes traceable failure class and correction evidence. |
| `05-corrected-replay.png` | Corrected replay succeeds against a local mock destination only. |
| `06-fix-report.png` | HTML report is generated locally from deterministic outputs. |
| `07-duplicate-guard.png` | Duplicate/idempotency guard refuses unsafe duplicate replay. |
| `08-quality-gates.png` | Local quality gates ran and passed when evidence was captured. |

Boundary: `fixture_safe=true`, `live_services_used=false`, `synthetic_data_only=true`.
